# 考研数学学习规划（含需求工程与设计工程）

## 一、需求工程
### 1. 定位
- 自我定位：信息与计算科学专业在读学生，已获四六级、普通话、计算机二级证书，目标攻读数学专业研究生，需通过系统备考提升成绩，进入理想院校。
- 考研认知：明确数学分析、高等代数、概率论与数理统计的考查范围及重点，清楚自身知识储备与目标院校要求的差距。

### 2. 功能
- 知识需求：熟练掌握数学分析（实数理论、级数理论）、高等代数（多项式理论、线性变换）、概率论（随机变量、分布函数）等核心知识点。
- 业务需求：满足考研应试要求，能准确高效解题，顺利完成试卷作答。
- 功能需求：具备获取优质资源（教材、网课、真题、习题集）、制定个性化计划、高效学习（钻研定理、刷题复盘）、模拟测试分析的能力。

### 3. 数据
- 实体设置：数学知识实体（含科目知识点及专业关联）、学习资源实体（教材/网课/真题等）、学习计划实体（各阶段计划）、测试成绩实体（模拟考/真题得分）。
- 实体关系：学习资源支撑知识学习，学习计划指导资源与知识的结合，测试成绩检验知识掌握程度。

### 4. 性能
- 暂未明确具体性能指标，后续结合设计工程补充。

### 5. 文本/资料/交付
- 调研材料：考研大纲、目标院校历年真题、参考教材（华东师大版数学分析、北大版高等代数等）、学长经验帖。
- 论证资料：目标院校选择、学习计划初步方案的论证文档。


## 二、设计工程（非技术部分）
### （一）业务设计部分（Ⅱ. 需求分析）
#### 1. 定位
- 宏观规划：覆盖基础、强化、冲刺全阶段，明确各阶段知识构建、解题能力、时间管理的目标与推进逻辑。
- 设计思想：以“夯实基础-提升能力-模拟应试”为核心，围绕知识体系与应试能力展开。

#### 2. 功能
- 业务功能规格书：
  - 基础阶段（现在-次年3月）：通读3科教材并整理笔记，结合专业笔记标注关联点。
  - 强化阶段（次年4-8月）：专题突破（中值定理、线性变换等）+ 大量刷题（《数学分析习题集》等）。
  - 冲刺阶段（次年9-12月）：真题模拟（近10年）+ 错题总结。
- 分活：
  - 活动：每天刷数学分析证明题（基础10道/天、强化15道/天）、高等代数计算题（基础8道/天、强化12道/天）等。
  - 手段：思维导图梳理知识（结合专业框架）、错题本按知识点分类（标专业关联）。
  - 表单：学习进度表（教材页数、习题数量）、测试成绩表（分数、题型得分）。
- 功能矩阵：基础阶段知识输入80%+解题20%，强化阶段知识输入40%+解题60%，冲刺阶段知识输入20%+解题应试80%。
- 业务功能一览表（规划版）：
  | 阶段   | 数学分析                | 高等代数                | 概率论                  |
  |--------|-------------------------|-------------------------|-------------------------|
  | 基础   | 2章/周，课后题20道/章   | 2章/周，课后题15道/章   | 1章/周，课后题10道/章   |
  | 强化   | 1专题/周，真题20道/专题 | 1专题/周，真题15道/专题 | 1专题/周，真题10道/专题 |
  | 冲刺   | 2套/周模拟卷，20道/套错题 | 2套/周模拟卷，20道/套错题 | 2套/周模拟卷，20道/套错题 |

#### 3. 数据
- 数据概要规格书：涵盖知识掌握程度（含专业关联）、学习时间、资源使用、成绩数据。
- 数据分类：按科目（数分/高代/概率论）、按类型（知识/时间/资源/成绩）分类。
- 数据规范：知识掌握用“理解（结合专业）-掌握（联系专业解题）-熟练运用（灵活用专业）”描述；时间单位“小时”（数分1.2-1.5小时/天）；成绩值域0-150分。
- 主数据规范：核心知识点编码（如MathAna-Limit-SeqLimit-CS，CS表专业关联）。
- 数据设计：Excel记录时间/成绩，计划/资源编号（如MathPlan-Ana-Basic-001-CS）。

#### 4. 性能
- 质量要求：计划合理（推进知识/提升能力）、资源优质（助力学习）、方法高效（最大化掌握程度）。

#### 5. 文本/资料/交付
- 需求规格说明书：详细说明知识掌握、进度、应试能力需求。
- 需求4件套：调研文档、分析报告、规格说明书、跟踪矩阵。


### （二）概要设计（Ⅲ. 概要设计）
#### 1. 定位
- 应用构造：结合专业知识设计学习场景，如用数值计算迭代思想理解数分极限，用矩阵编程经验强化高代矩阵运算。
- 应用架构：
  - 资源整合：基础阶段（教材+基础网课）、强化阶段（专题网课+习题集）、冲刺阶段（真题）。
  - 时间分配：基础（数分2h/天、高代2h/天、概率论1h/天）、强化（数分2.5h/天、高代2.5h/天、概率论1.5h/天）、冲刺（动态调整）。
- 机构选择：以自主学习为主，难知识点（实数连续性证明等）辅以辅导班/线上课。

#### 2. 功能
- 功能细节：
  - 功能应用规格书：思维导图以实数理论为核心，延伸极限/积分等，标专业应用（数值计算对极限的作用）；错题本按矩阵/线性变换分类，标专业关联（矩阵编程）。
  - 业务功能规格书（组件+件数）：
    - 数分组件：极限（5件：ε-N数列极限、ε-δ函数极限等）、积分（4件）、级数（3件）。
    - 高代组件：矩阵（4件：运算、对角化等）、线性变换（3件）、多项式（2件）。
    - 概率论组件：随机变量（3件：离散/连续/多维）、数字特征（2件）。
  - 业务构件一览表：数分证明构件（含中值定理证明等）、高代计算构件（含矩阵计算等）。
  - 系统功能：每天学习≥3小时（数分1.2h、高代1.2h、概率论0.6h），自主安排内容/时间。

#### 3. 数据
- 数据细节：
  - 数据详细规格书：数分成绩含专业关联题型得分（如数值近似积分证明题），时间记录到分钟（标专业回顾时长）。
  - 数据关系图：知识实体（含专业）-成绩实体（专业题型得分）关联，计划实体-时间实体（含专业时长）关联。
  - 数据格式：计划编号“MathPlan-科目-阶段-序号-CS”，成绩记录“日期|科目|分数|专业题型得分|排名”。
  - 数据关联：时间（含专业时长）与计划关联，分析计划执行/专业融合效果。

#### 4. 性能
- 数据模型：建立“学习输入（时间/资源）-知识掌握-测试输出（成绩）”模型，分析投入产出。
- 业务模型：用模型制定管理规划（如按掌握程度调计划）、判断学习状态（是否良性轨道）。
- 保证机制：数据质量（准确及时记录时间/成绩）、方法验证（对比成绩变化）。
- 应用价值：架构保障科目均衡推进，资源架构快速获取优质资源。

#### 5. 文本/资料/交付
- 概要设计规格书：说明阶段划分、核心任务、学习策略。
- 业务模型图：资源获取→知识学习→测试检验流程。
- 业务规划图：基础（教材学习+定理证明）、强化（专题+刷题）、冲刺（真题+错题）重点。
- 数据规范库：知识编码、数据记录规范。


### （三）详细设计（Ⅳ. 详细设计）
#### 1. 定位
- 应用细化：
  - 数分极限：每天1h，先回顾牛顿迭代法（专业），再练ε-N/ε-δ证明题，总结无穷大/单侧极限思路。
  - 高代特征值：每天1.5h，练不同阶矩阵求解/特征向量正交化，结合PCA降维（专业）理解应用。
  - 概率论分布：每天1h，梳理二项/正态分布定义/性质，结合蒙特卡洛模拟（专业）理解场景。
- 架构优化：每周日评估进度，数分积分掌握慢则从高代/概率论抽30分钟补，高代线性空间学好则加数分函数空间分析。

#### 2. 功能
- 功能深化：
  - 数分级数：细分正项/交错/函数项级数，总结判别法适用条件，练5-8道/天，结合函数近似展开（专业）分析收敛性对精度的影响。
  - 高代线性变换：结合标准基/正交基分析矩阵变化，用三维旋转（图形学专业）案例理解，练3-5道/天。
  - 概率论分布：对比离散/连续计算差异，制对比表（分布律/期望等），结合噪声分析（信号专业）理解场景。
- 系统功能调整：上午精力好则学数分，下午/晚上学高代/概率论，保证每天3-4小时。

#### 3. 数据
- 数据细化：
  - 数分极限掌握度：ε-N证明结合数值迭代理解，标“理解-掌握-熟练运用”。
  - 学习时间：Forest记录专注时长，手动标专业回顾时间（如学矩阵时回顾编程10分钟）。
  - 测试成绩：记录数分专业关联题型得分（如积分近似证明题），分析专业助力效果。

#### 4. 性能
- 保证强化：测试后记录错题知识点/原因（概念混淆/思路缺失），同一知识点多次错则换网课/找学长答疑。

#### 5. 文本/资料/交付
- 详细设计规格书：说明每周/每天任务（如周一数分中值定理学习+10道题）、时间分配细则。
- 数据件：Excel记录时间，数据库管理成绩。
- 业务4件套：详细设计文档、流程说明、操作规范、验证标准。
- 数据蓝图：数据产生（学习/测试）→流转（记录到Excel/数据库）→应用（分析进度）环节。


### （四）应用设计（Ⅴ. 应用设计）
#### 1. 定位
- 应用落地：
  - 时间管理：番茄工作法（25分钟专注+5分钟休息），休息时回顾专业关联（如学矩阵特征值想图像处理应用）。
  - 资源使用：真题按知识点分类（数分中值定理、高代矩阵对角化等），每天练1类，错题标专业关联（如逻辑推导类联系专业编程逻辑）。

#### 2. 功能
- 功能拓展：
  - 综合训练：每周2小时跨科目练习（如数分重积分+概率论均匀分布，解蒙特卡洛积分题），强化专业与考研融合。
  - 碎片化学习：Anki记公式（如傅里叶级数联系信号频域分析）、易错点（高代特征值漏重根）。

#### 3. 数据
- 数据应用：每周日用Excel做折线图，分析学习时间/专业关联时长与成绩（含专业题型得分）的关系，时间投入多但成绩差则调方法（如加专业结合课）。

#### 4. 性能
- 应用价值提升：优化资源渠道（关注目标院校老师推荐资料），按阶段调整时间分配，贴合备考需求。

#### 5. 文本/资料/交付
- 详细设计落地：每周用Word列每日任务（如“周一：数分中值定理学习+10道题”），标注完成情况。
- 交付成果：每月整理错题本（分类+错误原因）、思维导图、成绩分析报告，形成月度文档。
