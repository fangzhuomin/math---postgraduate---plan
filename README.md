| 1. 定位 | ■ 自我定位：信息与计算科学专业在读学生，已取得四六级、普通话、计算机二级证书，目标为攻读数学专业研究生，期望通过系统、科学的备考，在考研中取得优异成绩，顺利进入理想院校的数学专业深造<br>■ 明确考研涉及的数学学科，像数学分析、高等代数、概率论与数理统计等的考查范围与重点，同时清晰认知自身在数学专业知识储备上与目标院校要求存在的差距 | ■ 宏观 - 规划：从整体视角规划考研数学的全流程，涵盖基础、强化、冲刺等阶段，明确每个阶段在数学知识体系构建、解题能力培养、时间管理等方面的整体目标与推进逻辑<br>■ 设计思想确定：确立以“夯实数学基础 - 提升解题能力 - 模拟冲刺应试”为核心的考研数学学习设计理念，主线紧紧围绕数学专业知识体系构建与应试能力培养展开 | ■ 应用 - 构造：针对数学不同科目，例如数学分析里的极限、积分等内容，高等代数中的矩阵、线性空间等内容，构建具体且贴合实际的学习应用场景与方法<br>■ 架构 - 应用架构：搭建考研数学学习的应用架构，将各科目学习资源，如教材、网课、习题集、真题等进行整合，明确其使用流程，同时合理规划科目间学习时间与精力的分配架构<br>■ 架构 - 机构：结合自身学习习惯，以及学校课程安排、自习环境等外部条件，选择以自主学习为主，适当参与数学考研辅导班或线上课程为辅的学习组织形式 | ■ 应用 - 细化：在数学分析学习上，针对极限部分，每天安排1小时深入研究典型极限证明题，总结不同类型极限的求解思路；高等代数方面，聚焦矩阵的特征值与特征向量，通过大量例题练习，掌握其在不同题型中的应用；概率论则围绕随机变量分布，每日梳理一种分布的定义、性质及相关题型。<br>■ 架构 - 优化：根据学习进度和效果，动态调整各科目学习时间分配。若某段时间数学分析的积分内容掌握较慢，适当增加该部分学习时长，同时减少已熟练掌握的概率论部分的学习时间占比。 | ■ 应用 - 落地：利用番茄工作法，将数学学习时间划分为多个25分钟的专注时段，每完成一个时段进行5分钟休息。在学习资源使用上，把目标院校历年真题按知识点分类，每天选取一类进行针对性训练，做完后及时对照答案分析错题原因。 |
| 2. 功能 | ■ 知识需求（对）：<br> - 熟练掌握数学专业考研核心知识点，比如数学分析中的实数理论、级数理论等；高等代数里的多项式理论、线性变换等；概率论中的随机变量、分布函数等<br>■ 业务需求（用户）：<br> - 满足数学专业考研应试的业务需求，能够在考试过程中准确、高效地运用数学知识解题，顺利完成试卷作答<br>■ 功能需求（高层）：<br> - 具备获取优质数学学习资源的能力，像专业教材、名师网课、考研真题、经典习题集等；能够制定个性化的数学学习计划；可以开展高效的数学学习，例如专注钻研定理证明、定期刷题并复盘；能够进行数学模拟测试与分析等 | ■ 功能 - 规划：<br> - 业务功能规格书：明确数学考研各阶段的学习任务，基础阶段要完成数学分析、高等代数等教材的通读与笔记整理，强化阶段进行专题突破与大量刷题，冲刺阶段开展真题模拟与错题总结等<br> - 分活（活动、手段、表单）：确定各数学科目学习活动，如每天定量刷数学分析证明题、高等代数计算题等；学习手段包括使用思维导图梳理数学知识体系、用错题本按知识点分类整理错题等；还有用于记录数学学习进度、测试成绩的表单<br> - 功能矩阵：梳理数学考研各阶段、各科目所需具备的功能，基础阶段侧重数学知识输入功能，冲刺阶段侧重数学应试输出功能<br> - 业务功能一览表（规划版）：汇总数学考研全程各阶段、各科目（数学分析、高等代数、概率论等）的业务功能，形成规划层面的清单 | ■ 功能 - 细节：<br> - 功能应用规格书：详细说明各数学学习功能在实际中的应用方式，比如思维导图如何用于数学分析知识体系构建，错题本如何分类整理高等代数错题等<br> - 业务功能规格书（组件 + 件数）：将数学学习功能拆解为组件，数学分析学习组件包含极限、积分、级数等子组件，高等代数学习组件包含矩阵、线性变换、多项式等子组件，并明确各组件下的具体“件数”，如极限子组件包含数列极限、函数极限等子件<br> - 业务构件一览表（组件版）：列出数学各科目学习的业务构件，如数学分析证明构件、高等代数计算构件等及其包含的组件<br> - 系统功能（时限、权限）：明确各数学学习功能的时间限制，每天数学学习时长不低于3小时，其中数学分析、高等代数、概率论可根据难度分配时间，以及自身对各功能的使用权限，能自主安排数学学习内容与时间等 | ■ 功能 - 深化：数学分析的级数子组件，细分正项级数、交错级数等不同类型，针对每种类型，总结判别法的适用条件和典型例题，每天练习5 - 8道相应题目；高等代数的线性变换子组件，结合不同的线性空间基，分析线性变换矩阵的变化规律，通过具体案例加深理解；概率论的随机变量分布子组件，对比离散型和连续型随机变量分布的计算差异，编制对比表格辅助学习。<br> - 系统功能（调整）：根据实际学习效率，若上午学习数学分析时注意力更集中，就将数学分析的重点学习安排在上午，高等代数和概率论则分配到下午和晚上，确保每天数学学习总时长稳定在3 - 4小时。 | ■ 功能 - 拓展：除了常规的刷题和整理错题，每周专门抽出2小时，进行数学知识的跨科目综合应用训练，比如结合数学分析的积分和概率论的分布函数，解决一些综合性题目，提升知识的综合运用能力。同时，利用碎片化时间，通过手机APP进行数学公式和定理的记忆背诵。 |
| 3. 数据 | ■ 实体设置（主）：<br> - 数学知识实体（包含各数学科目知识点及其关联）、数学学习资源实体（教材、网课、习题、真题等）、数学学习计划实体（各阶段数学计划）、数学测试成绩实体（模拟考、真题练习数学成绩）<br>■ 实体关系：<br> - 数学知识实体与数学学习资源实体存在“支撑”关系，学习资源用于学习数学知识；数学学习计划实体与数学知识实体、数学学习资源实体存在“指导 - 被指导”关系，学习计划指导如何利用学习资源学习数学知识；数学测试成绩实体与数学知识实体存在“检验 - 被检验”关系，测试成绩检验对数学知识的掌握程度 | ■ 数据 - 规划：<br> - 数据概要规格书：概述考研数学学习过程中涉及的数据，如数学知识掌握程度数据（通过测试、作业等体现）、数学学习时间数据、数学学习资源使用数据、数学成绩数据等<br> - 数据分类：按数学科目（数学分析、高等代数、概率论等）分类数据，按数据类型（知识类、时间类、资源类、成绩类）分类数据<br> - 数据规范、规范值、值域：明确数学知识掌握程度数据用“理解、掌握、熟练运用”等规范描述，数学学习时间数据以“小时”为单位，值域根据科目难度等设定，如数学分析每天学习1.5 - 2小时，数学成绩类数据值域为0 - 满分，如数学分析真题卷满分150分<br> - 主数据规范：确定各数学科目核心知识点为主数据，明确其定义与编码规则，如数学分析主数据“极限 - 数列极限”编码为 MathAna - Limit - SeqLimit<br> - 数据设计、业务编号：设计数据存储结构，如用Excel表格记录每天数学学习时间、测试成绩等，对数学学习计划、数学学习资源等进行业务编号，如 MathPlan - Ana - Basic - 001 表示数学分析基础阶段学习计划001 | ■ 数据 - 细节：<br> - 数据详细规格书：详细说明各数据项的定义、格式、取值范围等，如数学分析测试成绩数据项，定义为“模拟考试或真题练习中数学分析科目的得分”，格式为“整数”，取值范围0 - 150<br> - 数据详细规格书：对数学学习时间数据，详细说明记录的时间粒度（如精确到分钟）、记录方式（手动记录或通过学习APP自动记录）等<br> - 数据关系图：绘制各数据实体间的关系图，如数学知识实体与数学测试成绩实体通过“知识点 - 得分”关联，数学学习计划实体与数学学习时间实体通过“计划 - 实际耗时”关联<br> - 数据格式：规定数学学习计划编号格式为“MathPlan - 科目 - 阶段 - 序号”，数学成绩记录格式为“日期 | 科目 | 分数 | 排名（若有）”等<br> - 数据（关联、值域、数据项）：明确数据项间的关联，如数学学习时间数据与数学学习计划数据关联，可分析数学计划执行情况，再次强调各数据项的值域，如高等代数某章节测试正确率值域为0 - 100% | ■ 数据 - 细化：数学分析的极限知识点掌握程度数据，细分“ε - N”“ε - δ”等不同证明方法的掌握情况，用“理解（能看懂证明）、掌握（能独立证明简单题目）、熟练运用（能解决复杂变形题目）”描述；数学学习时间数据记录到分钟，使用手机APP“Forest”自动记录专注学习数学的时长；数学测试成绩数据不仅记录分数，还记录各题型（证明题、计算题等）的得分情况，便于分析薄弱题型。 | ■ 数据 - 应用：每周日晚上，汇总本周数学学习时间数据和测试成绩数据，利用Excel的图表功能，生成学习时间分配与成绩变化的折线图，分析时间投入与成绩提升的相关性。若发现某科目学习时间增加但成绩提升不明显，就调整该科目学习方法，比如增加专题视频课的学习比例。 |
| 4. 性能 |  | ■ 质量要求：<br> - 数学学习计划的合理性，即能否有效推进数学知识学习、提升解题能力；数学学习资源的优质性，即对数学知识学习与解题能力提升的帮助程度；数学学习方法的高效性，即能否在有限时间内最大化数学知识掌握程度与解题能力等 | ■ 数据模型：<br> - 建立考研数学学习的数据模型，如“数学学习输入（时间、资源） - 知识掌握 - 测试输出（成绩）”的模型，用于分析数学学习投入与产出的关系<br> - 业务模型、管理规划、决策判断：基于数据模型，制定数学学习管理规划，如根据数学知识掌握程度数据调整数学学习计划，并能通过数学测试成绩等数据进行决策判断，如是否需要增加某数学科目学习时间<br> - 业务模型、管理规划、决策判断：利用数据模型分析自身数学学习状态，判断是否处于良性备考轨道，进而决策是否调整数学学习策略 | ■ 保证 - 机制：<br> - 建立数据质量保证机制，确保数学学习数据（如测试成绩、学习时间）记录的准确性与及时性；建立数学学习方法有效性验证机制，通过对比不同阶段数学成绩变化验证方法是否有效<br> - 应用价值的设计：<br> - 架构层：通过合理的数学学习架构设计（资源整合、时间分配），保障各数学科目学习的均衡推进与高效开展<br> - 架构层：通过应用架构（如数学资源获取与使用架构），确保能快速获取优质数学学习资源并有效利用 | ■ 保证 - 强化：每次测试后，详细记录错题的知识点、错误原因，并与之前的测试错题进行对比，若同一知识点多次出错，就判断该学习方法在该知识点上效果不佳，及时调整学习方法，比如针对该知识点找专门的辅导视频学习，或向同学请教更有效的学习技巧。 | ■ 应用价值 - 提升：在架构层，不断优化学习资源的获取渠道，关注目标院校老师的学术动态和推荐的参考资料，确保获取的资源更具针对性；在时间分配上，根据不同复习阶段的重点，灵活调整各科目学习时长，使学习架构始终贴合考研复习的需求，提升整体学习效率。 |
| 5. 文本、资料、交付 | ■ 需求调研材料汇总：<br> - 数学专业考研大纲、目标院校数学专业历年真题、参考书目（如数学分析教材、高等代数教材、概率论教材等）、数学考研学长学姐经验帖等调研材料的汇总整理<br> - 历次论证资料：对数学专业目标院校选择、数学学习计划初步方案等进行论证的资料 | ■ 需求规格说明书：<br> - 详细说明数学考研的需求，包括数学知识掌握程度需求、数学学习进度需求、数学应试能力需求等<br> - 需求4件套：涵盖数学考研需求调研、分析、规格说明等相关的文档集合（如数学需求调研文档、数学需求分析报告、数学需求规格说明书、数学需求跟踪矩阵） | ■ 概要设计规格书：<br> - 从整体上说明考研数学学习的设计，包括阶段划分、各阶段数学核心任务、整体数学学习策略等<br> - 业务模型图：展示考研数学学习的业务流程（如从数学资源获取到知识学习再到测试检验的流程）<br> - 业务规划图：规划数学考研全程各阶段的业务重点（如基础阶段业务重点是数学教材学习与基础定理证明，冲刺阶段是数学真题模拟与错题总结）<br> - 数据规范库等：汇总考研数学学习相关的数据规范（如数学知识编码规范、数学数据记录规范） | ■ 详细设计规格书：<br> - 对考研数学学习各方面进行详细设计说明，如数学分析、高等代数、概率论每一周的具体学习任务、每天的数学学习时间分配细则等<br> - 数据件：详细说明各数学数据项的存储、管理方式（如用Excel表格记录每天数学学习时间，用数据库管理数学测试成绩数据等）<br> - 业务4件套：涵盖数学业务详细设计、数学业务流程说明、数学业务操作规范、数学业务验证标准等文档<br> - 数据蓝图：描绘考研数学学习数据的整体蓝图，包括数据的产生、流转、应用等环节 | ■ 详细设计 - 落地：每周日制定下一周的详细学习计划，用Word文档详细列出每天数学分析、高等代数、概率论的具体学习任务，如“周一：数学分析，学习‘中值定理’章节，完成课后习题第1 - 10题；高等代数，复习‘矩阵的秩’，做真题中相关题目5道；概率论，学习‘二维随机变量分布’，整理笔记”。每天晚上对照计划，在文档中标记任务完成情况。 | ■ 交付 - 成果：每月末整理当月的数学学习资料，包括整理好的错题本（按科目、知识点分类，标注错误原因和正确解法）、总结的知识点思维导图、测试成绩分析报告等，形成月度学习成果文档，方便回顾复习和查找薄弱点。 |
