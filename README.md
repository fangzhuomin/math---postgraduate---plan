| 1. 定位 | ■ 自我定位：信息与计算科学专业在读学生，已取得四六级、普通话、计算机二级证书，目标为攻读数学专业研究生，期望通过系统、科学的备考，在考研中取得优异成绩，顺利进入理想院校的数学专业深造<br>■ 明确考研涉及的数学学科，像数学分析、高等代数、概率论与数理统计等的考查范围与重点，同时清晰认知自身在数学专业知识储备上与目标院校要求存在的差距 | ■ 宏观 - 规划：从整体视角规划考研数学的全流程，涵盖基础、强化、冲刺等阶段，明确每个阶段在数学知识体系构建、解题能力培养、时间管理等方面的整体目标与推进逻辑<br>■ 设计思想确定：确立以“夯实数学基础 - 提升解题能力 - 模拟冲刺应试”为核心的考研数学学习设计理念，主线紧紧围绕数学专业知识体系构建与应试能力培养展开 | ■ 应用 - 构造：结合信息与计算科学专业所学，针对数学分析里的极限（利用专业中数值计算的迭代思想辅助理解数列极限）、积分（联系专业中积分近似计算方法加深对积分概念的掌握）等内容，以及高等代数中的矩阵（借助专业中矩阵运算在编程中的应用经验，强化对矩阵乘法、逆矩阵等的理解）、线性空间（结合专业里向量空间的知识，构建线性空间的直观认知）等内容，构建具体且贴合实际的学习应用场景与方法<br>■ 架构 - 应用架构：搭建考研数学学习的应用架构，将各科目学习资源，如数学分析用的华东师范大学版教材、高等代数用的北大版教材，张宇考研数学网课、汤家凤考研数学网课，《数学分析习题集》《高等代数考研真题分类解析》《概率论与数理统计辅导讲义》等习题集，目标院校历年真题等进行整合，明确其使用流程，基础阶段以教材和基础网课为主，强化阶段结合专题网课和习题集，冲刺阶段主攻真题；同时合理规划科目间学习时间与精力的分配架构，基础阶段数学分析、高等代数各分配2小时/天，概率论1小时/天，强化阶段数学分析、高等代数各2.5小时/天，概率论1.5小时/天，冲刺阶段根据真题模拟情况动态调整<br>■ 架构 - 机构：结合自身在信息与计算科学专业课程学习中养成的自主学习习惯，以及学校数学分析、高等代数等课程的安排，还有图书馆、自习室等自习环境，选择以自主学习为主，在遇到难以攻克的知识点（如数学分析的实数连续性证明、高等代数的线性变换核与像等）时，适当参与数学考研辅导班或线上课程（如目标院校学长学姐的答疑课、知名考研机构的专题突破课）为辅的学习组织形式 | ■ 应用 - 细化：在数学分析学习上，针对极限部分，每天安排1小时，先回顾信息与计算科学专业中数值迭代的例子（如牛顿迭代法求根），再深入研究数学分析中典型的极限证明题（如利用“ε - N”“ε - δ”定义证明数列、函数极限），总结不同类型极限的求解思路（如数列极限为无穷大的情况、函数极限单侧极限的情况）；高等代数方面，聚焦矩阵的特征值与特征向量，每天花1.5小时，通过大量例题练习（如不同阶数矩阵的特征值求解、特征向量正交化），结合专业中矩阵在数据变换（如PCA 降维）中的应用，掌握其在相似对角化、二次型标准化等题型中的应用；概率论则围绕随机变量分布，每日花1小时梳理一种分布（如二项分布、正态分布）的定义、性质（期望、方差计算）及相关题型（如已知分布求概率、由概率反推分布参数），联系专业中随机模拟（如蒙特卡洛方法）对分布的应用场景，加深理解<br>■ 架构 - 优化：每周日对本周学习进度和效果进行评估，根据实际情况动态调整各科目学习时间分配。若某段时间数学分析的积分内容（如重积分、曲线曲面积分）掌握较慢，从高等代数或概率论的学习时间中每天抽调30分钟，增加该部分学习时长，同时减少已熟练掌握的概率论部分（如随机变量数字特征）的学习时间占比；若在高等代数的线性空间部分学习顺利，可适当增加该部分与数学分析应用结合的拓展学习（如用线性空间理论分析数学分析中的函数空间） | ■ 应用 - 落地：利用番茄工作法，将数学学习时间划分为多个25分钟的专注时段，每完成一个时段进行5分钟休息，休息时可快速回顾信息与计算科学专业中与当前学习数学知识点相关的内容（如学习矩阵特征值时，回忆专业中矩阵特征值在图像处理中的应用）。在学习资源使用上，把目标院校历年真题按知识点分类，每天选取一类（如数学分析的中值定理证明、高等代数的矩阵对角化、概率论的正态分布应用）进行针对性训练，做完后及时对照答案分析错题原因，对于错题，联系专业中类似的逻辑推导或计算问题，总结错误类型（如概念混淆、计算失误、思路缺失），并标注对应的专业知识关联点，便于后续复习
| 2. 功能 | ■ 知识需求（对）：<br> - 熟练掌握数学专业考研核心知识点，比如数学分析中的实数理论、级数理论等；高等代数里的多项式理论、线性变换等；概率论中的随机变量、分布函数等<br>■ 业务需求（用户）：<br> - 满足数学专业考研应试的业务需求，能够在考试过程中准确、高效地运用数学知识解题，顺利完成试卷作答<br>■ 功能需求（高层）：<br> - 具备获取优质数学学习资源的能力，像专业教材、名师网课、考研真题、经典习题集等；能够制定个性化的数学学习计划；可以开展高效的数学学习，例如专注钻研定理证明、定期刷题并复盘；能够进行数学模拟测试与分析等 | ■ 功能 - 规划：<br> - 业务功能规格书：明确数学考研各阶段的学习任务，基础阶段（现在 - 次年3月）要完成数学分析（华东师大版）、高等代数（北大版）、概率论与数理统计（浙大版）等教材的通读与笔记整理，结合信息与计算科学专业笔记，标注与专业知识的关联点；强化阶段（次年4 - 8月）进行专题突破（如数学分析的中值定理、级数，高等代数的线性变换、二次型，概率论的分布与数字特征）与大量刷题（《数学分析习题集》《高等代数考研真题分类解析》《概率论与数理统计辅导讲义》）；冲刺阶段（次年9 - 12月）开展真题模拟（目标院校近10年真题）与错题总结等<br> - 分活（活动、手段、表单）：确定各数学科目学习活动，如每天定量刷数学分析证明题（基础阶段10道/天，强化阶段15道/天）、高等代数计算题（基础阶段8道/天，强化阶段12道/天）、概率论综合题（基础阶段5道/天，强化阶段8道/天）等；学习手段包括使用思维导图梳理数学知识体系（结合专业知识框架，构建数学考研知识与专业知识的联合思维导图）、用错题本按知识点分类整理错题（标注与专业知识的联系）等；还有用于记录数学学习进度（每天完成的教材页数、习题数量）、测试成绩（模拟考分数、各题型得分）的表单<br> - 功能矩阵：梳理数学考研各阶段、各科目所需具备的功能，基础阶段侧重数学知识输入功能（教材阅读、笔记整理，结合专业知识理解），占比80%，解题功能占比20%；强化阶段知识输入功能占比40%，解题功能占比60%；冲刺阶段知识输入功能占比20%，解题与应试功能占比80%<br> - 业务功能一览表（规划版）：基础阶段，数学分析（2章/周，课后题20道/章）、高等代数（2章/周，课后题15道/章）、概率论（1章/周，课后题10道/章）；强化阶段，数学分析（1专题/周，真题20道/专题）、高等代数（1专题/周，真题15道/专题）、概率论（1专题/周，真题10道/专题）；冲刺阶段，全科模拟卷（2套/周，错题整理20道/套） | ■ 功能 - 细节：<br> - 功能应用规格书：详细说明各数学学习功能在实际中的应用方式，比如思维导图如何用于数学分析知识体系构建（以实数理论为核心，延伸出极限、连续、微分、积分等分支，同时标注专业中数值计算对极限的应用、积分近似计算对积分的应用），错题本如何分类整理高等代数错题（按知识点分为矩阵、线性变换、二次型等，每个错题标注与专业中矩阵运算编程、线性空间建模等的关联）等<br> - 业务功能规格书（组件 + 件数）：将数学学习功能拆解为组件，数学分析学习组件包含极限、积分、级数等子组件，极限子组件下有“ε - N 数列极限”“ε - δ 函数极限”“无穷大极限”等5件；高等代数学习组件包含矩阵、线性变换、多项式等子组件，矩阵子组件下有“矩阵运算”“矩阵对角化”“逆矩阵求解”等4件；概率论学习组件包含随机变量、数字特征、分布等子组件，随机变量子组件下有“离散型随机变量”“连续型随机变量”“多维随机变量”等3件<br> - 业务构件一览表（组件版）：列出数学各科目学习的业务构件，如数学分析证明构件（包含中值定理证明、积分证明等，关联专业中数值分析的误差证明）、高等代数计算构件（包含矩阵计算、线性方程组求解等，关联专业中线性方程组在数据分析中的应用）等及其包含的组件<br> - 系统功能（时限、权限）：明确各数学学习功能的时间限制，每天数学学习时长不低于3小时，其中数学分析、高等代数各1.2小时，概率论0.6小时，可根据难度和自身掌握情况在各科间微调，且自身对各功能有完全的自主安排学习内容与时间的权限 | ■ 功能 - 深化：数学分析的级数子组件，细分正项级数、交错级数、函数项级数等不同类型，针对每种类型，总结判别法（如正项级数的比较判别法、比值判别法，交错级数的莱布尼茨判别法）的适用条件和典型例题，每天练习5 -
